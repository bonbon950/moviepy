# Notes for Claude

This fork is used as Bjorn's **shorts video editor** (YouTube Shorts / TikTok / IG Reels clips of
Kai Cenat, TJR, Duke Dennis, Rakai, Fanum).

- **Before editing any short, read and follow `shorts/STYLE_GUIDE.md` (the rulebook).** Every rule in
  it came from Bjorn; do not break the hard rules in section 1.
- Tools live in `shorts/tools/`; an example edit plan is `shorts/edits/kai_nail_plan.py`.
- Libraries (SFX, music beds, beats, emoji) are rebuilt from the manifests with the fetch scripts;
  media files are not committed.
